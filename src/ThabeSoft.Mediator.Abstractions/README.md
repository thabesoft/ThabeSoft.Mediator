## 关于

提供中介者的抽象概念

## 如何使用

作为抽象层通常搭配具体实现使用，例如：

- `ThabeSoft.Mediator` 提供了请求和通知的实现

## 主要类型

该库提供的主要类型有：

- `ThabeSoft.DomainDrivenDesign.ISender`
- `ThabeSoft.DomainDrivenDesign.IPublisher`
- `ThabeSoft.DomainDrivenDesign.IMediator`
- `ThabeSoft.DomainDrivenDesign.IRequestHandler`
- `ThabeSoft.DomainDrivenDesign.INotificationHandler`
- `ThabeSoft.DomainDrivenDesign.IRequestPipelineBehavior`
- `ThabeSoft.DomainDrivenDesign.INotificationPipelineBehavior`
